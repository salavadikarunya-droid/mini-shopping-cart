# Mini Shopping Cart

This is a simple Java project where users can enter their own products and add them to a shopping cart.

## What it does

- Add multiple products
- Enter product name
- Enter product price
- Enter quantity
- Calculate the total for each product
- Calculate the final cart total
- Display all products in the cart

## Technologies Used

- Java
- Scanner
- ArrayList

## How to Run

Run the `Main.java` file in VS Code or any Java IDE.

The program will ask for:
- Number of products
- Product name
- Product price
- Quantity

It will then display the cart and calculate the total amount.

Java Console Application
